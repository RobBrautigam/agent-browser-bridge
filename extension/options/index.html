Every line shows the account signed into it. The bridge records who a profile was when you claimed it, and re-checks about once a minute while it is connected. If a different account is signed in, the claim is dropped, the line is renamed and disarmed, and nothing can be routed to it until you claim it again. Chrome carries the full check, because it records the Google account in its profile metadata. Brave records no account at all, so there the check falls back to the profile name: signing a Brave profile into a different account without renaming it cannot be detected, and renaming a Brave profile will unclaim the line and ask you to pick it again.

Arming

Arming a line lets Claude run arbitrary JavaScript inside that logged in browser session for a bounded window. Everything that session can reach, the script can reach. Reading, clicking, navigating and typing never need arming; only this does. Arming expires on its own and never carries over a browser restart.
